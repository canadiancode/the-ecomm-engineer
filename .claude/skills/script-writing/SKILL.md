# Script writing

Read first, in this order: `brand/corrections.md`, `brand/voice.md`, `brand/off-limits.md`, `brand/story.md`, `brand/audience.md`, `brand/strategy.md`. Use the `pbl-method` skill for hook types and structures.

## Constraints

- Kevin films **alone, on one phone**, at home. No second camera operator, no moving shots that need help.
- **30–60 seconds** spoken. About 2.5 words per second, so 75–150 words of `Say:` lines total. Count them.
- **Hook in the first 2 seconds:** spoken, text and visual hooks all land in SHOT 1.
- One idea per sentence. 5th-grade reading level. No jargon (see `brand/audience.md`).
- **Never invent facts about Kevin's life.** Anything not in `brand/story.md` → `(TO CONFIRM: what's needed)`. Same for any number, date, tool name or claim.
- Proof: every claim about a fix shows the demo store on screen. Demo-store numbers only. No revenue.
- Never name the employer, its clients or the agency.

## Format (Pipeline column J)

```
SETUP: <where the phone sits, framing, what I'm holding/props, what's added in edit>
SHOT 1 (hook, 0-2s) | Camera: <position, framing> | Do: <action> | Edit: <filename> | Say: "<line>"
SHOT 2 | Camera: same | Say: "<line>" | Edit: <filename>
...
SHOT N (CTA) | Camera: same, lean in | Say: "<CTA line>"
Note: <anything Kevin needs to prep: screen recordings to capture, photos to add>
```

- **SETUP line is mandatory**: where the phone sits (tripod, desk, shelf), framing (chest up / waist up / side angle), what I'm holding. The spare broken phone is a good prop (hold to the lens, scroll and put it face down, show a screen added in edit).
- Each SHOT is `[camera/action] + what I say`. Omit `Do:` or `Edit:` when not needed. Keep `Camera: same` when nothing changes, so Kevin can film straight through.
- **Cutaways reference real Drive files by exact filename**: `Edit: forestry_working_in_field.JPG`. Use the filename tables in `brand/story.md` (B-Roll/Story). For screen recordings, name the file Kevin should record and save to `B-Roll/Screen Recordings`, e.g. `Edit: demo_store_upsell.mp4 (TO RECORD)`. For a photo that doesn't exist yet: `Edit: burnaby_trail_work.jpg (TO ADD to B-Roll/Story)`.
- Bleeping: swearing stays by default. Write `(bleep)` after a word only if it should be bleeped.
- Kevin says the Video ID at the start of every take; don't script it. The Notes cell says: `Say "Video 0NN" before each take.`

## Filling the row

| Column | Rule |
| --- | --- |
| C Topic | plain-words title |
| D Pillar | one of the 8 in `brand/strategy.md` |
| E Hook type / F Structure | from pbl-method, exact names |
| G Spoken hook | same as the SHOT 1 Say line |
| H Text hook | ≤ 6 words, on screen during SHOT 1, adds to the spoken hook rather than repeating it |
| I Visual hook | what you see in SHOT 1 |
| J Script | format above |
| K Caption | a different job from the video (context, series counter, question, keyword reminder). 1–3 short lines. No hashtag walls (max 3). Never "link in bio". |
| L CTA keyword | value videos: ≤7 letters, caps, tied to a lead magnet. Story: `Follow` |
| M Format | Talking head / Talking head + screen / Voiceover + B-roll / Whiteboard / Two-person |
| N Status | `Scripted` |
| T Notes | `Say "Video 0NN" before each take.` + prep list + every TO CONFIRM item + source Idea ID and formula used |

## Self-check before saving (all must pass)

1. SETUP line present. SHOT 1 is the hook, with all three layers.
2. `Say:` word count 75–150 (write the count in Notes, e.g. `~118 words / ~47s`).
3. No hype words or money flexing (`brand/voice.md`), no jargon (`brand/audience.md`), no "link in bio".
4. Nothing from `brand/off-limits.md`. Only demo-store numbers.
5. Every life fact is in `brand/story.md`, otherwise it's marked `(TO CONFIRM)`.
6. Every `Edit:` filename exists in Drive or is marked TO ADD / TO RECORD.
7. Caption doesn't repeat the hook. CTA keyword ≤7 letters.
8. Story videos: one chapter only, ends with what it means for the viewer. Value videos: one personal line from Kevin's story.
9. Nothing contradicts `brand/corrections.md`.
