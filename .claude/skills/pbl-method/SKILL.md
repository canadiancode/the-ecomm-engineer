# PBL method (Personal Brand Launch / Ava Yuergens)

The idea: don't guess what works. Find videos that already beat their own audience, break down why, turn that into a reusable formula, and run it through Kevin's story and voice.

## 1. Outlier rule

A video is worth studying when **both** are true:

- views ≥ `'Start here'!B6` (now 700,000), and
- views ≥ `'Start here'!B7` × followers (now 5×).

Read B5:B7 each run. Use only numbers seen on the source. If one is unknown, say "outlier status: unknown" in Notes. Videos below the rule can still go in Ideas (Kevin's saves, niche fits), but Notes must say so, e.g. `Below the 5× rule (1.0×).` Helpful extra signal: views vs the creator's median of recent posts (`1,521x this creator's median`).

## 2. The 3-layer hook (first 2 seconds)

Every video needs all three, and they should work together, not repeat each other:

| Layer | Column | Example |
| --- | --- | --- |
| Spoken | Spoken hook | "I used to measure trees for a living. Now I build Shopify stores." |
| Text on screen | Text hook | "Forestry → Shopify → dev lead" |
| Visual | Visual hook | Spare phone held to the lens, then lowered to reveal me at the desk |

When analyzing, write what's actually there. If a layer is missing, write `none` and note it as a weakness.

## 3. The 7 hook types

Use these exact names in the Hook type column. One topic can become up to 7 videos, one per hook type.

| Hook type | What it does | Template |
| --- | --- | --- |
| Shock | Surprising claim or contrast | "[Unexpected fact about X]." |
| Comprehensive | Promises the full list or system | "Every [thing] you need to [result], ranked." |
| Common Mistake | Calls out an error the viewer makes | "If your store does [X], you're losing [Y]." |
| Comparison | Two or more options side by side | "[A] vs [B]: which one actually [result]?" |
| Question | Asks what the viewer is wondering | "Why do [people] [problem]?" |
| Negative | Says what not to do, or pushes back | "Stop [common advice]." / "Nobody tells you this about [X]." |
| Tutorial | How to, step by step | "How to [result] in [time/steps]." |

## 4. The 11 structures

Use these exact names in the Structure column. Educational structures drive comments (leads). Story structures drive shares (reach).

| Structure | Beats | Best for |
| --- | --- | --- |
| Hero's Journey | ordinary life → call → struggle → change → what it means for you | story |
| About Me | who I am → path in 4–6 fast beats → what I do now → why follow | pinned intro |
| The Lesson | hook → the lesson → 2–3 proof points or steps → apply it | value / story |
| The Big Goal | where I'm going → why → what it takes → follow the journey | story / building in public |
| Challenge to Victory | goal → obstacle → low point → turn → result | story |
| The Breakthrough | stuck → the moment it clicked → what changed | story / tool demos |
| 3 Levels | beginner → better → best version of the same thing | value |
| 2 People | two characters (owner A vs owner B) doing it differently | value / relatable |
| X vs X | two options compared on the same points → verdict | value |
| Action-Result | show the action → show the result → how to do it | demos, demo-store fixes |
| Did You Know | surprising fact → why it matters → what to do | news, value |

## 5. The formula

Every outlier gets a fill-in-the-blank formula: the hook and structure with the specifics swapped for `[brackets]`, so it works for any topic.

- Bad: "Ranking ingredients for a brand." (too vague)
- Good: "Ranking every [ingredient] you need to [build a brand] in [year], from least to most important."

When we use a formula, fill the brackets with Kevin's world (demo store, Shopify support days, his story) and rewrite in `brand/voice.md`. Drop hype words but keep the structure.

## 6. Caption

The caption does a **different job** from the video: context, fine print, a series counter, a question to drive comments, or the keyword reminder. Never repeat the spoken hook word for word.

## 7. CTA

- Value videos: **comment a keyword** (7 letters or fewer, caps). ManyChat sends the DM. Say it on camera and put it in the caption.
- Story videos: follow CTA tied to what's next.
- Never "link in bio". Never "follow me!" with nothing attached.
- Broad hook, narrow value, niche CTA, so the people who comment are store owners.

## 8. Winners and re-films

- A **winner** is ≥ `'Start here'!B5` (5×) Kevin's **platform** average views (Analytics column M).
- Every winner gets re-filmed with a **new hook** (a different one of the 7 types) and, where it fits, a new format (whiteboard, two-person, voiceover over B-roll) or a noun swap for another store type.
- Losers aren't failures. Note what was different (hook type, length, first frame).

## 9. Breakdown checklist (for any link)

1. Platform, account, link, views, followers (only what's visible). Outlier math.
2. Spoken / text / visual hook, verbatim.
3. Hook type (one of 7) and structure (one of 11).
4. Formula with `[brackets]`.
5. Why it worked, in one sentence. What the caption does.
6. Fit for The Ecomm Engineer: which pillar, which personal line, what Kevin can prove on the demo store. Flag anything that conflicts with `brand/off-limits.md` or `brand/voice.md`.
